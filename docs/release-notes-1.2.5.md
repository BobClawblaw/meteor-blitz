# Meteor Blitz 1.2.5

- **Removed explosion scorch decals:** Completely removed the dark ragged soot decals (`scorch_texture` / `draw_scorches`, a port addition from the original 2026-10-29 port) that stamped black splotches onto the planet backdrop and clouds for 15 seconds after explosions.
- **Everything else intact:** Dynamic lighting, normal-mapped planets, shockwaves, bloom, ship trails/shield rim, and all three particle modes (`Classic`, `Physics`, `Gas Physics`) remain unchanged.
