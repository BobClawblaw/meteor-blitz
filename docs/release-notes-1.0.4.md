# Meteor Blitz 1.0.4

- **HIGH SCORES shows your scores.** It opens the score table straight away, with **Arcade** and **Survival** tabs to switch tables. (It used to go through a mode picker titled "Select Mode" that looked like the Play menu.)
- **HELP shows help.** It plays the interactive tutorial, as the original game did, and returns to the main menu when it ends or when you press Quit. The key and controller bindings are under SETTINGS > Controls.

The web version (https://bobclawblaw.github.io/meteor-blitz/) has these changes too.

## Downloads

- **macOS** (`MeteorBlitz-1.0.4-macos.dmg`): universal app for Apple Silicon and Intel, macOS 11 or later. Open the DMG and drag Meteor Blitz to Applications. The app is not notarised, so on first launch macOS asks for permission: right-click the app and choose Open, or allow it under System Settings > Privacy & Security.
- **Windows** (`MeteorBlitz-1.0.4-windows.zip`): unzip anywhere and run `MeteorBlitz.exe`. Windows SmartScreen may warn about an unrecognised app; choose More info > Run anyway.

Settings, bindings and scores carry over from earlier versions.
