# Meteor Blitz 1.0.7

- **Planets wrap cleanly.** The HD terrain and fog textures now crossfade at their edges, so the backdrop repeats without the visible line that appeared on the green-haze world and the other planets. The normal maps were regenerated from the fixed textures.
- **Startup resolution on high-DPI displays.** The window size now uses the display's backing scale rather than the window's scale before it is shown, so a saved resolution is not set at half size at launch.

The web version (https://bobclawblaw.github.io/meteor-blitz/) keeps the original-resolution art; the desktop HD art has the seamless wrap.

## Downloads

- **macOS** (`MeteorBlitz-1.0.7-macos.dmg`): universal app for Apple Silicon and Intel, macOS 11 or later. Open the DMG and drag Meteor Blitz to Applications. The app is not notarised, so on first launch macOS asks for permission: right-click the app and choose Open, or allow it under System Settings > Privacy & Security.
- **Windows** (`MeteorBlitz-1.0.7-windows.zip`): unzip anywhere and run `MeteorBlitz.exe`. Windows SmartScreen may warn about an unrecognised app; choose More info > Run anyway.

Settings, bindings and scores carry over from earlier versions.
