# Meteor Blitz 1.0.3

- **Shots leave the front of the ship.** Fire, laser and cannon shots used to start at the ship's centre, and a fresh shot's trail reached back through the ship, so the flamethrower looked like it came out of the tail. Shots now leave from the nose and their trails never reach behind it.
- **Smaller downloads.** All images are losslessly recompressed (same pixels): the macOS download drops from 110 to 104 MB and the Windows download from 99 to 91 MB.
- **The web version loads much faster.** Its download drops from 24.1 to 13.6 MB, mostly by using compressed audio in the browser. Play it at https://bobclawblaw.github.io/meteor-blitz/

## Downloads

- **macOS** (`MeteorBlitz-1.0.3-macos.dmg`): universal app for Apple Silicon and Intel, macOS 11 or later. Open the DMG and drag Meteor Blitz to Applications. The app is not notarised, so on first launch macOS asks for permission: right-click the app and choose Open, or allow it under System Settings > Privacy & Security.
- **Windows** (`MeteorBlitz-1.0.3-windows.zip`): unzip anywhere and run `MeteorBlitz.exe`. Windows SmartScreen may warn about an unrecognised app; choose More info > Run anyway.

Settings, bindings and scores carry over from earlier versions.
