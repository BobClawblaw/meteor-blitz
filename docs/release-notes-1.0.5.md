# Meteor Blitz 1.0.5

- **Esc goes back one level everywhere.** On the Play, World, Stage and High Scores screens, Esc now does what the back arrow (or B on a controller) does: Stage > World > Mode > main menu. Options, Controls and the pause menu already worked this way; on the main menu Esc still quits.
- **Leaving the tutorial returns to the main menu.** Quitting the HELP tutorial through its pause menu used to land on the World 1 stage select.
- **The score table's messages fit the screen.** "NO SCORES YET" and "GLOBAL SCORES OFFLINE" were drawn wider than the screen and cut off at the edges.

The web version (https://bobclawblaw.github.io/meteor-blitz/) has these changes too.

## Downloads

- **macOS** (`MeteorBlitz-1.0.5-macos.dmg`): universal app for Apple Silicon and Intel, macOS 11 or later. Open the DMG and drag Meteor Blitz to Applications. The app is not notarised, so on first launch macOS asks for permission: right-click the app and choose Open, or allow it under System Settings > Privacy & Security.
- **Windows** (`MeteorBlitz-1.0.5-windows.zip`): unzip anywhere and run `MeteorBlitz.exe`. Windows SmartScreen may warn about an unrecognised app; choose More info > Run anyway.

Settings, bindings and scores carry over from earlier versions.
