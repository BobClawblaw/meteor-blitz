# Meteor Blitz 1.1.3

- **Physics particles keep the original effects.** With Options > Particle style set to Physics, explosions, shot hits, bombs, a breaking shield and the ship's destruction now show the original game's effects with the new fire, sparks, debris and smoke on top. Before, Physics replaced the original effects instead of adding to them.

The web version (https://bobclawblaw.github.io/meteor-blitz/) has the same change.

## Downloads

- **macOS** (`MeteorBlitz-1.1.3-macos.dmg`): universal app for Apple Silicon and Intel, macOS 11 or later. Open the DMG and drag Meteor Blitz to Applications. The app is not notarised, so on first launch macOS asks for permission: right-click the app and choose Open, or allow it under System Settings > Privacy & Security.
- **Windows** (`MeteorBlitz-1.1.3-windows.zip`): unzip anywhere and run `MeteorBlitz.exe`. Windows SmartScreen may warn about an unrecognised app; choose More info > Run anyway.
- **Linux / Steam Deck** (`MeteorBlitz-1.1.3-linux-x86_64.tar.gz`): extract it and run `MeteorBlitz/meteor-blitz`. `MeteorBlitz/install.sh` adds the game to the application menu, so on a Steam Deck (in Desktop Mode) Steam's "Add a Non-Steam Game" lists it. Saves go to `~/.local/share/meteor-blitz`. This build has been tested on a Linux PC but not yet on a Steam Deck.

Settings, bindings and scores carry over from earlier versions.
